# FlClash 二次开发（Android）

基于 [FlClash](https://github.com/chen08209/FlClash)，拼夕夕订阅自动同步 + **开梯子个人流量计费回传面板**。

| 项目 | 正版 | 二次开发版 |
|------|------|-----------|
| 平台 | Android / 多端 | **仅 Android APK** |
| 应用名 | FlClash | FlClash 二次开发 |
| 包名 | com.follow.clash | com.wzpxx.flclash.dev |
| 控制端口 | 9090 | 9190 |
| 拼夕夕订阅 | 默认 24h | **10 秒同步** |
| 流量计费 | 无 | **VPN 开启后每 10 秒上报面板** |
